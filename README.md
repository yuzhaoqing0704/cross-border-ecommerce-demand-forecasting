# Identifying High-Potential Product Categories in Cross-Border Trade Using Data Analytics and Machine Learning

Final project for **IT270 – Data Mining for Business Analytics** (Hofstra University, May 2026). Grade: A.

## Overview
Motivated by an interest in cross-border trade, this project analyzes a Kaggle cross-border e-commerce supply chain dataset to identify which product categories have the highest future demand potential — and what drives that demand.

## Data
- Kaggle cross-border e-commerce / supply chain dataset
- Key variables: product category, country/market, pricing, marketing activity, logistics cost, shipping mode, inventory levels
- Target variable: `Demand_Next_Period`

## Methods
- **Exploratory data analysis**: examined how product category, country, pricing, marketing activity, logistics cost, shipping mode, and inventory levels relate to future demand
- **Modeling**: built and compared **Multiple Linear Regression** vs **Decision Tree Regression** to predict future demand
- **Validation**: train-validation-holdout splits with model performance evaluation

## Deliverables
- 25-page analytical report with business recommendations on product selection, inventory planning, shipping strategy, and market entry for international trading companies

## Tools
Python · pandas · scikit-learn · Jupyter Notebook
